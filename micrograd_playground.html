The Derivative
Video: 08:08
+20 pts

Core Idea

A derivative answers: "If I nudge input x by a tiny amount, how much does the output f(x) change?"

f'(x) = limh→0 [f(x+h) − f(x)] / h

Think of it as the slope of the tangent line at point x. Positive slope = function going up. Negative slope = going down. Zero slope = minimum or maximum.

💡 We approximate it numerically with a tiny h = 0.00001

Partial Derivatives
Video: 14:12
+20 pts

Core Idea

When a function has multiple inputs, we measure sensitivity to each input separately, holding others fixed. This is called a partial derivative.

d = a·b + c ∂d/∂a = b (treat b,c as constants) ∂d/∂b = a (treat a,c as constants) ∂d/∂c = 1 (treat a,b as constants — always 1)

💡 Intuition: if you nudge a by h, d changes by h·b. So the slope w.r.t. a is exactly b.

The Chain Rule
Video: 19:09
+20 pts

Core Idea

When functions are composed (chained), derivatives multiply along the path:

If L = g(d) and d = f(a), then: dL/da = dL/dd · dd/da = (local grad at L) × (local grad at d)

In our expression L = (a·b + c) · f:

Variables: a=2, b=−3, c=10, f=−2 Step 1: e = a·b = −6 Step 2: d = e+c = 4 Step 3: L = d·f = −8 dL/dd = f = −2 (local: how L changes with d) dd/de = 1 (local: how d changes with e) de/da = b = −3 (local: how e changes with a) dL/da = dL/dd · dd/de · de/da = (−2)·(1)·(−3) = 6

💡 Think of it like a domino chain: each local gradient tells you how much that one step magnifies or shrinks the change.

Backpropagation
Video: 32:10 — 01:17:32
+20 pts

Core Idea

Backpropagation is the chain rule applied automatically to every node in a computation graph, starting at the output and walking backwards.

Algorithm: 1. Seed: output.grad = 1.0 (dL/dL = 1) 2. Topological sort (order nodes root → leaves) 3. For each node (in reverse order): call node._backward() — applies local chain rule

Each operation knows its own local gradient formula:

add: self.grad += 1.0 × out.grad (grad passes through unchanged) mul: self.grad += other.data × out.grad (grad = other × out.grad) tanh: self.grad += (1 − tanh²) × out.grad

💡 Note the += not = ! A node may receive gradient from multiple paths (e.g. if used twice). Both contributions accumulate.

Gradient Descent
Video: 51:10
+20 pts

Core Idea

After backprop gives us all gradients, we update each weight to reduce the loss:

w.data = w.data − lr × w.grad

The gradient points uphill (direction of increasing loss). So we subtract it to go downhill.

If w.grad > 0: decreasing w will decrease L → w goes down If w.grad < 0: increasing w will decrease L → w goes up If w.grad = 0: already at a flat point, no change

Learning rate (lr) controls step size. Too large = overshoot. Too small = slow convergence.

A Single Neuron
Video: 52:52 — 01:09:02
+20 pts

Core Idea

A neuron computes a weighted sum of inputs, adds a bias, then squishes through a nonlinearity:

n = x₁·w₁ + x₂·w₂ + b (pre-activation) o = tanh(n) (activation output in −1..+1)

The tanh gradient is: do/dn = 1 − tanh(n)² = 1 − o²

By the chain rule, gradients for each weight:

do/dw₁ = (1 − o²) · x₁ do/dw₂ = (1 − o²) · x₂ do/dx₁ = (1 − o²) · w₁ do/db = (1 − o²) · 1

💡 Notice: when |o| ≈ 1 (saturated), 1−o² ≈ 0. Gradients vanish! This is the "vanishing gradient" problem.
